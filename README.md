# Prévia visual: Comida Caseira do Silvio

Landing page conceitual não oficial criada como demonstração comercial.

- Projeto estático: HTML, CSS e JavaScript
- Sem banco de dados, API ou painel administrativo
- Imagens culinárias ilustrativas geradas para a demonstração
- Links de WhatsApp e mapa apontam para os dados públicos exibidos pelo restaurante

O material não representa uma página oficial do Restaurante Comida Caseira do Silvio.
